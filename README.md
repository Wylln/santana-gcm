# Meu Edital GCM Santana 2026 (PWA + APK Android)

Aplicativo web progressivo (**PWA**) e pacote nativo Android (**.APK**) para organização dos estudos do **Concurso Público nº 001/2026 da Prefeitura Municipal de Santana/AP — Guarda Civil Municipal (GCM)**.

---

## 🌐 Como publicar no GitHub para acessar pela internet (GitHub Pages)

Sim! Todos os arquivos desta pasta foram configurados com caminhos relativos (`./`) e arquivo `.nojekyll`, prontos para funcionar imediatamente no **GitHub Pages** com HTTPS, Service Worker offline e botão para download do `.APK`:

1. Acesse o [GitHub](https://github.com/) e crie um novo repositório público (ex.: `meu-edital-gcm-santana-2026`).
2. Na página do repositório criado, clique em **Add file** → **Upload files**.
3. Arraste **todos os arquivos e pastas** deste diretório (`index.html`, `manifest.json`, `sw.js`, `.nojekyll`, `Meu-Edital-GCM-Santana-2026.apk`, pastas `css/`, `js/`, `icons/`, `.github/`) para o GitHub e clique em **Commit changes**.
4. No menu superior do repositório no GitHub, vá em **Settings** (Configurações) → **Pages** (no menu lateral esquerdo).
5. Em **Build and deployment** → **Source**, escolha **Deploy from a branch**, selecione a branch **`main`** (ou `master`) e a pasta **`/ (root)`**, e clique em **Save**.
6. Em cerca de 1 minuto seu site estará no ar no endereço:
   `https://SEU-USUARIO.github.io/meu-edital-gcm-santana-2026/`

## 📱 Como instalar o arquivo `.APK` no celular Android

O arquivo instalador Android já está compilado e assinado digitalmente (V1 + V2 + V3) dentro desta pasta:
- **Arquivo:** `Meu-Edital-GCM-Santana-2026.apk`

### Passo a passo no celular:
1. Envie o arquivo `Meu-Edital-GCM-Santana-2026.apk` para o seu celular Android (via WhatsApp, Telegram, Google Drive, cabo USB, ou clicando no botão **"Baixar .APK"** direto pelo site publicado no GitHub Pages).
2. Toque no arquivo `Meu-Edital-GCM-Santana-2026.apk` no celular.
3. Caso o Android exiba um aviso de *"Instalar apps desconhecidos"*, toque em **Configurações** e ative **Permitir desta fonte**.
4. Caso o Google Play Protect exiba o aviso padrão para aplicativos novos de estudo sem publicação na Play Store, toque em **Mais detalhes** → **Instalar assim mesmo**.
5. Pronto! O aplicativo **Meu Edital GCM Santana 2026** aparecerá na gaveta de aplicativos do seu Android e funciona **100% offline** desde o primeiro segundo (todo o conteúdo do edital está embutido dentro do `.APK`).
